Definition. Generalized element [0002]

  • October 30, 2026
  • Hsu Ching Chung

Let A be an object in a category \mathcal {C}. A generalize element of A is a morphism into A x : \Gamma \rightarrow A. The source \Gamma of x is called the context of x. In the case \mathcal {C} has terminal object 1, a generalized element x : 1 \rightarrow A of A whose context is the terminal object 1 is called a global element of A.

    Notation of generalized elements [000D]

    • November 2, 2026
    • Hsu Ching Chung

    Let \mathcal {C} be a category. In general, for an object A in \mathcal {C}, we can not talk about what is an element of A. But from the categorical semantics of type theory or in the lens of Yoneda lemma (do not worry if you did not heard about them), it seems to be a great idea to consider generalized elements of A.

    The notation of generalized elements makes reasoning about objects like working with "sets." For the reader who knows the Yoneda embedding, it can be viewed as a converter sending an object A to its generalized elements \operatorname {Hom}_\mathcal {C}(-, A) grouped by contexts, where \operatorname {Hom}_\mathcal {C}(-, A) denotes the contravariant hom functor of A.     Proposition. Justification of the name of global elements [0004]

    • October 30, 2026
    • Hsu Ching Chung

    Fix an object A in a category \mathcal {C} with a terminal object 1.

    An assignment (a_\Gamma )_\Gamma of a generalized element a_\Gamma : \Gamma \rightarrow A of A for each object \Gamma in \mathcal {C} is called a global assignment of generalized elements of A if it is invariant under context substitution in the sense that: a_\Delta \sigma = a_\Gamma for all morphisms \sigma : \Gamma \rightarrow \Delta in \mathcal {C}.

    Show that there is a one-to-one correspondence between global elements c : 1 \rightarrow A of A and global assignments of generalized elements (a_\Gamma )_\Gamma of A.

    Proof.

    • October 30, 2026
    • Hsu Ching Chung

    Given a global element c : 1 \rightarrow A of A, we can consider the assignment of generalized elements of A: c {!}_\Gamma : \Gamma \rightarrow 1 \rightarrow A for each object \Gamma , where the morphism {!}_\Gamma : \Gamma \rightarrow 1 is the unique morphism into the terminal object 1. Then (c {!}_\Gamma )_\Gamma is invariant under context substitution since for any morphism \sigma : \Gamma \rightarrow \Delta , we have {!}_\Gamma = {!}_\Delta \sigma by the uniqueness of {!}_\Gamma , and so c {!}_\Gamma = c {!}_\Delta \sigma .

    Conversely, let (a_\Gamma )_\Gamma be a global assignment of generalized elements of A. We have a global element a_1 : 1 \rightarrow A of A.

    We check that these two constructions are inverses of each other:

    • c {!}_1 = c: Since {!}_1 = \operatorname {id}_1 : 1 \rightarrow 1 by the uniqueness of {!}_1, we have c {!}_1 = c \operatorname {id}_1 = c.
    • a_1 {!}_\Gamma = a_\Gamma : Since (a_\Gamma )_\Gamma is "invariant under context substitution", taking \sigma := {!}_\Gamma : \Gamma \rightarrow 1 gives a_1 {!}_\Gamma = a_\Gamma .

      Exercise. Properties of u \le v and u \sim v [000A]

      • October 31, 2026
      • Hsu Ching Chung

      For any monomorphisms u,u',v,v',w into A in a category \mathcal {C} and generalized element x of A, show the following:

      1. u \le v if and only if u factor through v.
      2. u \sim v if and only if u = v \phi for some isomorphism \phi : U \cong V, where U, V are the source of u : U \hookrightarrow A, v : V \hookrightarrow A respectively.
      3. The relation \le defines a preorder on monomorphisms into A:
        • u \le u.
        • If u \le v and v \le w then u \le w.
      4. The relation \sim defines a equivalence relation on monomorphisms into A:
        • u \sim u.
        • If u \sim v then v \sim u.
        • If u \sim v and v \sim w then u \sim w.
      5. Both relations x \in u and u \le v are well defined with respect to the equivalent relation u \sim v, that is:
        • If u \sim u' then x \in u if and only if x \in u'.
        • If u \sim u' and v \sim v' then u \le v if and only if u' \le v'.

      For monomorphisms u, v into the same object A in a category \mathcal {C}, we say u is included in v, denoted by u \le v, if x \in u \text { implies } x \in v for all generalized elements x of A. Recall that x \in u denotes the subobject membership relation.

      Definition. Subobject membership relation [0007]

      • October 31, 2026
      • Hsu Ching Chung

      Let x : \Gamma \rightarrow A be a generalized element of an object A and u : U \hookrightarrow A be a monomorphism in a category \mathcal {C}. We say x is lying in u, denoted by x \in u, if x factors through u; that is, we have x = u \phi for some morphism \phi : \Gamma \rightarrow U.

      Notice that such a \phi is unique: if x = u \phi and x = u \psi for some \phi , \psi : \Gamma \rightarrow U, then u \phi = u \psi , which implies \phi = \psi since u is a monomorphism.
